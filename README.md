# payments-api

A small Express + TypeScript service that issues and captures charges.

## Run

```bash
npm install
npm run dev   # http://localhost:3000
```

## Routes

| Method | Path                | Description            |
|--------|---------------------|------------------------|
| GET    | `/healthz`          | Liveness probe         |
| POST   | `/charges`          | Create a charge        |
| POST   | `/charges/:id/capture` | Capture a charge    |
| GET    | `/charges/:id`      | Fetch a charge         |

## Deploy

Containerised via the root `Dockerfile`; Helm chart under `chart/`.
